Rocks paper scissors

Proof of concept of a provably fair rock paper scissors game:

the computer provides his guess first, but the user discovers
the computer guess only after his own guess has been submitted

to check if the computer cheated: perform a sha1 hash of the
computer guess + nonce and compare it to the computer result hash
that have been provided before the user guess
