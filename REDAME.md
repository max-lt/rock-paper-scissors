# Code assignment: Rock Paper Scissors

## Development setup

### Install dependencies
Worker
```bash
cd worker 
npm i
```

Webapp
```bash
cd webapp 
npm i
```

### Set your Cloudflare account ID in /worker/wrangler.toml (uncommitted)
```toml
account_id = "..."
```

### Run project
Worker
```bash
npm start
```

Webapp
```bash
npm start
```
